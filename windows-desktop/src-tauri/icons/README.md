# Icons

Place your application icons here:

- `32x32.png` - 32x32 pixel icon
- `128x128.png` - 128x128 pixel icon
- `128x128@2x.png` - 256x256 pixel icon (2x resolution)
- `icon.icns` - macOS icon
- `icon.ico` - Windows icon

You can use the default Tauri icons or generate your own using tools like:
- https://tauri.app/v1/guides/features/icons
- https://icon.kitchen/
